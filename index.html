Context beats prompting.

        

          Prompts ask for work. Context trains the agent before the work starts. `SELLER.md` is the sales memory layer your AI tools should read before touching anything customer-facing.
        

        

          

            01 / capture
            
Write down how you sell: market, ICP, personas, proof, objections, claims, and voice.

          

          

            02 / attach
            
Add the file to Claude Projects, ChatGPT Projects/GPTs, Gemini Gems, Codex, Cursor, or your local agent folder.

          

          

            03 / run
            
Use it before Greenfield, POV, Account Expansion, Executive Briefing, QBR, and First Call Deck workflows.

          

        

        

          

            anti-slop
            
Blocks vague outreach, unsupported claims, fake personalization, and feature-tour decks.

          

          

            sales memory
            
Keeps messaging that worked, closed-lost lessons, pricing precedent, and customer language.

          

          

            agent-ready
            
Plain Markdown. Easy for humans to edit and easy for AI agents to read.
