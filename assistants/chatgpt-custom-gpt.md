# ChatGPT handoff

The recommended website action copies the draft-first prompt for the seller to paste into the conversation or project with their relevant sales context. A new chat or configured assistant may not expose the same memory, files, or connections.

The website also offers an Open ChatGPT link with the prompt in the URL. This is a convenience, not a guarantee of prefill or context access; retain the visible copy/manual-copy fallback.

If configuring an assistant, use assistants/instructions.md with the root SELLER.md template. Suggested starters:

- Create my SELLER.md from context available to you.
- Interview me instead.
- Refresh the SELLER.md I already have.

Do not assume an assistant inherits the user's history or connected accounts. Verify actual access before promising source-assisted drafting.
